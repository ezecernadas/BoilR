# Autosync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Tauri app stays in the Windows tray, notices when the set of importable games changed, and imports it without the user opening BoilR, never restarting Steam under a running game.

**Architecture:** A pure state machine (`autosync/machine.rs`) holds the behaviour table and is driven by a Tokio runner (`autosync/runner.rs`) that runs a full check every `interval_minutes` and a cheap probe every 5 s while something is pending. Change detection (`detect.rs`) compares the app ids the import would write with the BoilR-owned ids already in `shortcuts.vdf`. All OS access sits behind two small traits (`Probes` for "is Steam / a game running", `Work` for settings, checks and the import), so everything except the Windows shell (tray, plugins, prompt window, Windows probes) is unit-tested on Linux.

**Tech Stack:** Rust (Tauri 2, Tokio, sysinfo 0.38, winreg 0.52, windows-sys 0.61), tauri-plugin-single-instance / -autostart / -notification (v2), React 19 + TypeScript + Tailwind (Vite).

**Spec:** `docs/superpowers/specs/2026-10-02-autosync-design.md`

## Global Constraints

- Settings defaults, verbatim: `[autosync]` `enabled = false`, `interval_minutes = 5`, `countdown_seconds = 60`, `start_with_windows = true`; the block is required in `crates/boilr-core/src/defaultconfig.toml` (there is no `#[serde(default)]`).
- `"autosync"` is added to the section blacklist in `load_setting_sections`.
- Probe tick: every 5 s while the state is not `Idle`. Full check: every `interval_minutes`. `paused` skips checks.
- Prompt window label `autosync-prompt`; commands `autosync_restart_now` and `autosync_not_now`; the countdown is its own window (notification actions are mobile-only).
- Prompt copy: "N new games. Steam restarts in 60 s", buttons **Restart now** and **Not now**. Playing copy: "N new games, they will be imported when you stop playing".
- Tray menu: Open BoilR, Sync now, Pause autosync, Quit. Tooltip examples: "Up to date", "2 games pending", "Blocked: Epic".
- Autostart registers the app with the `--background` argument; with it the main window starts hidden.
- When any enabled platform snapshot has an error, the check reports "blocked" and autosync does nothing in that cycle. Manual import keeps today's behaviour.
- Steam's stop/start in autosync is driven by the machine, not by `stop_steam` / `start_steam`; `ensure_steam_started` runs after the import whatever the import returned.
- Never identify processes by PID (match by executable path or name).
- Windows-only code is behind `#[cfg(windows)]` with a non-Windows stub; on other systems autosync is unavailable and the setting is hidden.
- No `unwrap`, `expect`, `panic`, `todo` or slice indexing in non-test code (propagate with `?`, `eyre` or `Result<_, String>`).
- `code_name()` values never change (Game Pass stays `gamepass`).
- When `apps/boilr-tauri/Cargo.lock` or `package-lock.json` change, run `apps/boilr-tauri/flatpak/update-sources.sh` and commit `cargo-sources.json` and `node-sources.json`.
- CI for the Tauri app runs `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and `cargo test`; root CI runs `cargo fmt --all --check`, `cargo clippy --all-targets -- -D warnings`, `cargo clippy -p boilr --lib --no-default-features -- -D warnings`.

## Review Focus

1. **Steam is closed when an import fails.** The spec's `Deferred + Steam closed → Syncing` rule combined with the 5 s probe would retry the failing import every 5 s. Expected: a failed import is not retried until the user picks Sync now or the change set changes. Test: Task 2, `failed_import_is_not_retried_when_steam_is_closed`.
2. **No enabled launcher returns data while BoilR shortcuts exist in Steam.** `perform_full_sync` returns early in that case (`apps/boilr-tauri/src/main.rs:333-344`), so a reported change would never clear and the prompt would come back every interval. Expected: no change reported. Test: Task 3, `no_platform_data_is_no_change`.
3. **Odd game folders.** Quoted `start_dir`s, a drive root, the Windows folder, and the doubled backslashes `libraryfolders.vdf` stores (`crates/boilr-core/src/steam/installed_games.rs:43` reads them raw). Expected: a drive root or `%WinDir%` never makes "a game is running" permanently true, and escaped paths still match. Tests: Task 5, `game_dirs_cleans_quotes_roots_and_duplicates`, `windows_folder_is_never_a_game_folder`, `doubled_backslashes_match`.
4. **The countdown ends after the user closed Steam.** With `restart_steam: true` the executor would start Steam the user just closed (`ensure_steam_started` starts it whenever it is not running, `restarter.rs:171-203`). Expected: import without starting Steam. Test: Task 2, `countdown_deadline_with_steam_closed_imports_without_restart`.
5. **Started with `--background` while autosync is off** (a stale autostart entry). Expected: the main window is shown, not an invisible app. Test: Task 7, `background_start_is_hidden_only_when_autosync_runs`.

```rust
//! Settings for automatic sync, the `[autosync]` block of the config file.

use std::time::Duration;

use serde::{Deserialize, Serialize};

/// Below this, the prompt would restart Steam before anyone could read it.
pub const MIN_COUNTDOWN_SECONDS: u64 = 10;

#[derive(Debug, Serialize, Deserialize, Clone, PartialEq, Eq)]
pub struct AutosyncSettings {
    pub enabled: bool,
    pub interval_minutes: u64,
    pub countdown_seconds: u64,
    pub start_with_windows: bool,
}

impl Default for AutosyncSettings {
    /// The same values as the `[autosync]` block of `defaultconfig.toml`.
    fn default() -> Self {
        Self {
            enabled: false,
            interval_minutes: 5,
            countdown_seconds: 60,
            start_with_windows: true,
        }
    }
}

impl AutosyncSettings {
    /// Time between two checks. A hand-edited 0 would make the check loop spin.
    pub fn interval(&self) -> Duration {
        Duration::from_secs(self.interval_minutes.max(1).saturating_mul(60))
    }

    /// Time between the prompt appearing and Steam being restarted.
    pub fn countdown(&self) -> Duration {
        Duration::from_secs(self.countdown_seconds.max(MIN_COUNTDOWN_SECONDS))
    }
}
```

```rust
pub fn load_setting_sections() -> eyre::Result<HashMap<String, String>> {
    let content = std::fs::read_to_string(get_config_file())?;
    Ok(parse_setting_sections(&content))
}

/// Splits a config file into its `[section]` bodies, leaving out the sections that belong
/// to `Settings` itself, so only platform sections remain.
fn parse_setting_sections(content: &str) -> HashMap<String, String> {
    let mut result = HashMap::new();
    let mut current_section_lines: Vec<String> = vec![];
    let mut current_section_name: Option<String> = Option::None;
    for line in content.lines() {
        if line.starts_with('[') && line.ends_with(']') {
            add_sections(&current_section_name, &current_section_lines, &mut result);
            current_section_name = line.get(1..line.len() - 1).map(|s| s.to_string());
            current_section_lines.clear();
        } else {
            current_section_lines.push(line.to_string());
        }
    }
    add_sections(&current_section_name, &current_section_lines, &mut result);

    let blacklisted_sections = ["steamgrid_db", "steam", "autosync"];
    for section in blacklisted_sections {
        let _ = result.remove(section);
    }
    result
}
```

  - `fn plural(count: usize, noun: &str) -> String`
  - `struct ChangeSet { pub added: BTreeSet<u32>, pub removed: BTreeSet<u32> }` with `is_empty()`, `count() -> usize`, `summary() -> String`; derives `Debug, Clone, Default, PartialEq, Eq`

  - `enum State { Idle, WaitingForGame { change }, Countdown { change, deadline: Millis }, Deferred { change, after_failure: bool }, Syncing { change, restart_steam: bool } }`
  - `enum Event { Checked { result, steam_running, game_running, now }, Probed { steam_running, game_running, now }, RestartNow, NotNow, SyncNow { steam_running, game_running }, SyncFinished { error: Option<String> } }`
  - `enum Effect { ShowPrompt { change, deadline }, HidePrompt, Notify(String), StartSync { restart_steam: bool } }`
  - `struct Machine` with `new(countdown_ms: Millis)`, `state(&self) -> &State`, `set_countdown(&mut self, countdown_ms: Millis)`, `handle(&mut self, Event) -> Vec<Effect>`, `reset(&mut self) -> Vec<Effect>`

Spec deviations made here, each pinned by a test: `Syncing` and `Deferred` carry the change set (needed for "Deferred with the same change set"); `SyncFinished` carries the error text (needed for the error notification); `SyncNow` carries the probe readings; `Deferred { after_failure: true }` is not retried when Steam is found closed (Review Focus 1); a countdown that ends with Steam closed imports without restarting (Review Focus 4); `Countdown + SyncNow` behaves like Restart now; `Idle + SyncNow` is handled by the runner (Task 6) as an immediate check.

```rust
#[cfg(test)]
mod tests {
    use super::*;

    const COUNTDOWN: Millis = 60_000;

    fn change(added: &[u32], removed: &[u32]) -> ChangeSet {
        ChangeSet {
            added: added.iter().copied().collect(),
            removed: removed.iter().copied().collect(),
        }
    }

    fn machine_in(state: State) -> Machine {
        let mut machine = Machine::new(COUNTDOWN);
        machine.state = state;
        machine
    }

    fn changed(change: &ChangeSet, steam_running: bool, game_running: bool, now: Millis) -> Event {
        Event::Checked {
            result: CheckResult::Changed(change.clone()),
            steam_running,
            game_running,
            now,
        }
    }

    fn no_change(now: Millis) -> Event {
        Event::Checked {
            result: CheckResult::NoChange,
            steam_running: true,
            game_running: false,
            now,
        }
    }

    fn probed(steam_running: bool, game_running: bool, now: Millis) -> Event {
        Event::Probed {
            steam_running,
            game_running,
            now,
        }
    }

    fn playing_text(change: &ChangeSet) -> String {
        format!("{}, they will be imported when you stop playing", change.summary())
    }

        assert_eq!(change(&[1], &[]).summary(), "1 new game");
        assert_eq!(change(&[1, 2], &[]).summary(), "2 new games");
        assert_eq!(change(&[], &[3]).summary(), "1 game removed");
        assert_eq!(change(&[1, 2], &[3]).summary(), "2 new games, 1 removed");
```

```rust
//! The autosync behaviour table as a pure state machine. No Tauri, no OS calls and no
//! clock: time comes in with the events, as milliseconds since the Unix epoch.

use std::collections::BTreeSet;

pub type Millis = u64;

pub const WAITS_FOR_GAME: &str = "A game is running. The import waits until you stop playing.";

pub fn plural(count: usize, noun: &str) -> String {
    if count == 1 {
        format!("1 {noun}")
    } else {
        format!("{count} {noun}s")
    }
}

/// What a sync would change in Steam: app ids it would add and remove. Its identity tells
/// a deferred change from a new one.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct ChangeSet {
    pub added: BTreeSet<u32>,
    pub removed: BTreeSet<u32>,
}

impl ChangeSet {
    pub fn is_empty(&self) -> bool {
        self.added.is_empty() && self.removed.is_empty()
    }

    pub fn count(&self) -> usize {
        self.added.len() + self.removed.len()
    }

    pub fn summary(&self) -> String {
        match (self.added.len(), self.removed.len()) {
            (added, 0) => plural(added, "new game"),
            (0, removed) => format!("{} removed", plural(removed, "game")),
            (added, removed) => format!("{}, {removed} removed", plural(added, "new game")),
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum CheckResult {
    NoChange,
    Changed(ChangeSet),
    /// An enabled launcher failed: syncing now would delete its games from Steam.
    Blocked { platforms: Vec<String> },
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum State {
    Idle,
    WaitingForGame { change: ChangeSet },
    Countdown { change: ChangeSet, deadline: Millis },
    /// `after_failure`: the import failed, so finding Steam closed does not retry it;
    /// only Sync now or a different change set does.
    Deferred { change: ChangeSet, after_failure: bool },
    Syncing { change: ChangeSet, restart_steam: bool },
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Event {
    Checked {
        result: CheckResult,
        steam_running: bool,
        game_running: bool,
        now: Millis,
    },
    Probed {
        steam_running: bool,
        game_running: bool,
        now: Millis,
    },
    RestartNow,
    NotNow,
    SyncNow {
        steam_running: bool,
        game_running: bool,
    },
    SyncFinished {
        error: Option<String>,
    },
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Effect {
    ShowPrompt { change: ChangeSet, deadline: Millis },
    HidePrompt,
    Notify(String),
    StartSync { restart_steam: bool },
}

pub struct Machine {
    state: State,
    countdown_ms: Millis,
}

impl Machine {
    pub fn new(countdown_ms: Millis) -> Self {
        Self {
            state: State::Idle,
            countdown_ms,
        }
    }

    pub fn state(&self) -> &State {
        &self.state
    }

    pub fn set_countdown(&mut self, countdown_ms: Millis) {
        self.countdown_ms = countdown_ms;
    }

    pub fn handle(&mut self, event: Event) -> Vec<Effect> {
        let state = std::mem::replace(&mut self.state, State::Idle);
        let (next, effects) = self.transition(state, event);
        self.state = next;
        effects
    }

    /// Back to `Idle`, for when autosync is switched off. A running import finishes first.
    pub fn reset(&mut self) -> Vec<Effect> {
        match self.state {
            State::Syncing { .. } => Vec::new(),
            State::Countdown { .. } => {
                self.state = State::Idle;
                vec![Effect::HidePrompt]
            }
            _ => {
                self.state = State::Idle;
                Vec::new()
            }
        }
    }

    fn transition(&self, state: State, event: Event) -> (State, Vec<Effect>) {
        match (state, event) {
            (
                state,
                Event::Checked {
                    result: CheckResult::Blocked { .. },
                    ..
                },
            ) => (state, Vec::new()),
            (State::Syncing { .. }, Event::SyncFinished { error: None }) => {
                (State::Idle, Vec::new())
            }
            (State::Syncing { change, .. }, Event::SyncFinished { error: Some(error) }) => (
                State::Deferred {
                    change,
                    after_failure: true,
                },
                vec![Effect::Notify(format!(
                    "Import failed: {error}. Pick Sync now in the tray to try again."
                ))],
            ),
            (state @ State::Syncing { .. }, _) => (state, Vec::new()),
            (
                State::Idle,
                Event::Checked {
                    result: CheckResult::Changed(change),
                    steam_running,
                    game_running,
                    now,
                },
            ) => self.start(change, steam_running, game_running, now),
            (State::Idle, _) => (State::Idle, Vec::new()),
            (
                _,
                Event::Checked {
                    result: CheckResult::NoChange,
                    ..
                },
            ) => (State::Idle, vec![Effect::HidePrompt]),
            (
                State::Deferred {
                    change: deferred,
                    after_failure,
                },
                Event::Checked {
                    result: CheckResult::Changed(change),
                    steam_running,
                    game_running,
                    now,
                },
            ) => {
                if change == deferred {
                    self.probe(
                        State::Deferred {
                            change,
                            after_failure,
                        },
                        steam_running,
                        game_running,
                        now,
                    )
                } else {
                    self.start(change, steam_running, game_running, now)
                }
            }
            (
                State::WaitingForGame { .. },
                Event::Checked {
                    result: CheckResult::Changed(change),
                    steam_running,
                    game_running,
                    now,
                },
            ) => self.probe(
                State::WaitingForGame { change },
                steam_running,
                game_running,
                now,
            ),
            (
                State::Countdown {
                    change: shown,
                    deadline,
                },
                Event::Checked {
                    result: CheckResult::Changed(change),
                    steam_running,
                    game_running,
                    now,
                },
            ) => {
                let mut effects = Vec::new();
                if change != shown {
                    effects.push(Effect::ShowPrompt {
                        change: change.clone(),
                        deadline,
                    });
                }
                let (next, more) = self.probe(
                    State::Countdown { change, deadline },
                    steam_running,
                    game_running,
                    now,
                );
                effects.extend(more);
                (next, effects)
            }
            (
                state,
                Event::Probed {
                    steam_running,
                    game_running,
                    now,
                },
            ) => self.probe(state, steam_running, game_running, now),
            (State::Countdown { change, .. }, Event::RestartNow | Event::SyncNow { .. }) => {
                let (next, mut effects) = Self::sync(change, true);
                effects.insert(0, Effect::HidePrompt);
                (next, effects)
            }
            (State::Countdown { change, .. }, Event::NotNow) => (
                State::Deferred {
                    change,
                    after_failure: false,
                },
                vec![Effect::HidePrompt],
            ),
            (
                state @ (State::Deferred { .. } | State::WaitingForGame { .. }),
                Event::SyncNow {
                    steam_running,
                    game_running,
                },
            ) => Self::sync_now(state, steam_running, game_running),
            (state, _) => (state, Vec::new()),
        }
    }

    /// What the latest readings mean for a waiting state.
    fn probe(
        &self,
        state: State,
        steam_running: bool,
        game_running: bool,
        now: Millis,
    ) -> (State, Vec<Effect>) {
        match state {
            State::WaitingForGame { change } if !game_running => {
                if steam_running {
                    self.start_countdown(change, now)
                } else {
                    Self::sync(change, false)
                }
            }
            State::Countdown { change, deadline } if now >= deadline => {
                let (next, mut effects) = if !steam_running {
                    // The user closed Steam meanwhile: import, but don't start it again.
                    Self::sync(change, false)
                } else if game_running {
                    (State::WaitingForGame { change }, Vec::new())
                } else {
                    Self::sync(change, true)
                };
                effects.insert(0, Effect::HidePrompt);
                (next, effects)
            }
            State::Deferred {
                change,
                after_failure: false,
            } if !steam_running => Self::sync(change, false),
            other => (other, Vec::new()),
        }
    }

    fn start(
        &self,
        change: ChangeSet,
        steam_running: bool,
        game_running: bool,
        now: Millis,
    ) -> (State, Vec<Effect>) {
        if !steam_running {
            Self::sync(change, false)
        } else if !game_running {
            self.start_countdown(change, now)
        } else {
            let text = format!(
                "{}, they will be imported when you stop playing",
                change.summary()
            );
            (State::WaitingForGame { change }, vec![Effect::Notify(text)])
        }
    }

    fn start_countdown(&self, change: ChangeSet, now: Millis) -> (State, Vec<Effect>) {
        let deadline = now.saturating_add(self.countdown_ms);
        (
            State::Countdown {
                change: change.clone(),
                deadline,
            },
            vec![Effect::ShowPrompt { change, deadline }],
        )
    }

    fn sync(change: ChangeSet, restart_steam: bool) -> (State, Vec<Effect>) {
        (
            State::Syncing {
                change,
                restart_steam,
            },
            vec![Effect::StartSync { restart_steam }],
        )
    }

    fn sync_now(state: State, steam_running: bool, game_running: bool) -> (State, Vec<Effect>) {
        let change = match &state {
            State::Deferred { change, .. } | State::WaitingForGame { change } => change.clone(),
            _ => return (state, Vec::new()),
        };
        if !steam_running {
            Self::sync(change, false)
        } else if !game_running {
            Self::sync(change, true)
        } else {
            (state, vec![Effect::Notify(WAITS_FOR_GAME.to_string())])
        }
    }
}
```

```rust
//! Whether the games BoilR would import differ from the BoilR games already in Steam.
//! `plan_sync` can't answer this: it lists every BoilR shortcut as a removal, because a
//! sync removes them all and re-adds the current set.

use std::collections::{BTreeSet, HashMap};

use boilr_core::{
    settings::Settings,
    steam::{get_shortcuts_for_user, get_shortcuts_paths},
    sync::IsBoilRShortcut,
};

use super::machine::{ChangeSet, CheckResult};
use crate::{prepare_additions, PlatformSnapshot};

/// Compares the app ids a sync would write (`desired`) with the BoilR-owned ids in Steam
/// (`current`).
pub fn detect(
    snapshots: &[PlatformSnapshot],
    settings: &Settings,
    renames: &HashMap<u32, String>,
    current: &BTreeSet<u32>,
) -> CheckResult {
    // A sync removes every BoilR shortcut and re-adds what answered: a failing launcher's
    // games would be deleted, so do nothing this cycle.
    let failing: Vec<String> = snapshots
        .iter()
        .filter(|snapshot| snapshot.enabled && snapshot.shortcuts.is_none())
        .map(|snapshot| snapshot.display_name.clone())
        .collect();
    if !failing.is_empty() {
        return CheckResult::Blocked { platforms: failing };
    }

    // With no launcher data `perform_full_sync` returns before touching Steam, so a
    // difference here could never be resolved.
    if !snapshots
        .iter()
        .any(|snapshot| snapshot.enabled && snapshot.shortcuts.is_some())
    {
        return CheckResult::NoChange;
    }

    let (_, desired) = prepare_additions(snapshots, settings, renames);
    let desired: BTreeSet<u32> = desired.into_iter().collect();
    let change = ChangeSet {
        added: desired.difference(current).copied().collect(),
        removed: current.difference(&desired).copied().collect(),
    };
    if change.is_empty() {
        CheckResult::NoChange
    } else {
        CheckResult::Changed(change)
    }
}

/// App ids of the BoilR-owned shortcuts in `shortcuts.vdf`, over every Steam user. An
/// unreadable file is an error: the check can't tell what is in Steam.
pub fn current_owned_ids(settings: &Settings) -> Result<BTreeSet<u32>, String> {
    let users = get_shortcuts_paths(&settings.steam).map_err(|err| err.to_string())?;
    let mut ids = BTreeSet::new();
    for user in users {
        let info = get_shortcuts_for_user(&user).map_err(|err| err.to_string())?;
        ids.extend(
            info.shortcuts
                .iter()
                .filter(|shortcut| shortcut.is_boilr_shortcut())
                .map(|shortcut| shortcut.app_id),
        );
    }
    Ok(ids)
}
```

```rust
//! matched by executable path, never by PID.

    sync::Arc,

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum GameSignal {
    /// A process runs from a Steam library or an imported game's folder.
    GameFolderProcess,
    /// `HKCU\Software\Valve\Steam\RunningAppID` is not 0.
    SteamRunningApp,
    /// Windows reports a full-screen app (`SHQueryUserNotificationState`).
    FullScreen,

    fn game_signals(&self) -> Vec<GameSignal>;
    /// Folders whose programs count as games, refreshed by every full check.
    fn set_game_dirs(&self, dirs: Vec<PathBuf>);
}

/// Lower case, `\` separators, no repeated or trailing separators, no surrounding quotes.
fn normalize(raw: &str) -> String {
    let mut out = String::with_capacity(raw.len());
    for ch in raw.trim().trim_matches('"').chars() {
        let ch = if ch == '/' { '\\' } else { ch };
        if ch == '\\' && out.ends_with('\\') {
            continue;
        }
        out.extend(ch.to_lowercase());
    }
    while out.ends_with('\\') {
        out.pop();
    }
    out
}

/// A drive root or an empty path would make every program look like a game.
fn is_specific_dir(normalized: &str) -> bool {
    normalized.trim_start_matches('\\').contains('\\')
}

fn starts_with_dir(path: &str, dir: &str) -> bool {
    path == dir
        || path
            .strip_prefix(dir)
            .is_some_and(|rest| rest.starts_with('\\'))
}

/// Whether `exe` lives under one of `dirs`. Programs under the Windows folder never count:
/// Xbox shortcuts launch through `explorer.exe`.
pub fn is_in_game_dir(exe: &Path, dirs: &[PathBuf], windows_dir: &Path) -> bool {
    let exe = normalize(&exe.to_string_lossy());
    if starts_with_dir(&exe, &normalize(&windows_dir.to_string_lossy())) {
        return false;
    }
    dirs.iter()
        .any(|dir| starts_with_dir(&exe, &normalize(&dir.to_string_lossy())))
}

/// Cleans raw folder strings (shortcut start folders, Steam libraries, Xbox install
/// folders) into a de-duplicated list of specific folders.
pub fn game_dirs(raw: impl IntoIterator<Item = String>) -> Vec<PathBuf> {
    let mut seen = BTreeSet::new();
    raw.into_iter()
        .map(|dir| normalize(&dir))
        .filter(|dir| is_specific_dir(dir))
        .filter(|dir| seen.insert(dir.clone()))
        .map(PathBuf::from)
        .collect()
}
```

```rust
    fn process_in_game_dir(&self) -> bool {
        let dirs = match self.dirs.read() {
            Ok(dirs) => dirs.clone(),
            Err(poisoned) => poisoned.into_inner().clone(),
        };
        if dirs.is_empty() {
            return false;
        }
        let mut system = System::new();
        system.refresh_processes_specifics(
            ProcessesToUpdate::All,
            true,
            ProcessRefreshKind::nothing().with_exe(UpdateKind::OnlyIfNotSet),
        );
        system
            .processes()
            .values()
            .filter_map(|process| process.exe())
            .any(|exe| is_in_game_dir(exe, &dirs, &self.windows_dir))
    }

    fn steam_reports_running_app() -> bool {
        RegKey::predef(HKEY_CURRENT_USER)
            .open_subkey(r"Software\Valve\Steam")
            .and_then(|key| key.get_value::<u32, _>("RunningAppID"))
            .map(|app_id| app_id != 0)
            .unwrap_or(false)
    }

    fn full_screen_app() -> bool {
        let mut state = 0;
        // SAFETY: the call writes one QUERY_USER_NOTIFICATION_STATE into `state`, a live
        // local for the whole call.
        let result = unsafe { SHQueryUserNotificationState(&mut state) };
        result >= 0
            && matches!(
                state,
                QUNS_BUSY | QUNS_RUNNING_D3D_FULL_SCREEN | QUNS_PRESENTATION_MODE
            )
    }
```

```rust
    }

    pub fn send(&self, input: RunnerInput) -> Result<(), String> {
        match &self.inputs {
            Some(inputs) => inputs
                .send(input)
                .map_err(|_| "Autosync has stopped".to_string()),
            None => Err("Autosync is only available on Windows".to_string()),
        }
    }

    /// Closing the main window hides it instead of quitting while this is true.
    pub fn keeps_running(&self) -> bool {
        let status = lock_status(&self.status);
        status.available && status.enabled
    }
}

pub fn now_ms() -> Millis {
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(millis)
        .unwrap_or(0)
}

fn millis(duration: Duration) -> Millis {
    u64::try_from(duration.as_millis()).unwrap_or(u64::MAX)
}

/// The tray tooltip and the settings page status line.
pub fn describe(state: &State, enabled: bool, paused: bool, blocked: &[String]) -> String {
    if !enabled {
        return "Autosync is off".to_string();
    }
    if paused {
        return "Autosync paused".to_string();
    }
    if !blocked.is_empty() {
        return format!("Blocked: {}", blocked.join(", "));
    }
    match state {
        State::Idle => "Up to date".to_string(),
        State::Syncing {
            restart_steam: true,
            ..
        } => "Restarting Steam and importing games".to_string(),
        State::Syncing { .. } => "Importing games".to_string(),
        State::WaitingForGame { change }
        | State::Countdown { change, .. }
        | State::Deferred { change, .. } => format!("{} pending", plural(change.count(), "game")),
    }
}

fn describe_result(result: &CheckResult) -> String {
    match result {
        CheckResult::NoChange => "No changes".to_string(),
        CheckResult::Changed(change) => change.summary(),
        CheckResult::Blocked { platforms } => {
            format!("Blocked: {} could not be read", platforms.join(", "))
        }
    }
}

pub struct Runner {
    machine: Machine,
    settings: Option<Settings>,
    paused: bool,
    blocked: Vec<String>,
    work: Arc<dyn Work>,
    probes: Arc<dyn Probes>,
    ui: Arc<dyn AutosyncUi>,
    status: SharedStatus,
}

impl Runner {
    pub fn new(
        work: Arc<dyn Work>,
        probes: Arc<dyn Probes>,
        ui: Arc<dyn AutosyncUi>,
        status: SharedStatus,
    ) -> Self {
        Self {
            machine: Machine::new(millis(AutosyncSettings::default().countdown())),
            settings: None,
            paused: false,
            blocked: Vec::new(),
            work,
            probes,
            ui,
            status,
        }
    }

    pub fn is_idle(&self) -> bool {
        matches!(self.machine.state(), State::Idle)
    }

    pub fn interval(&self) -> Duration {
        self.settings
            .as_ref()
            .map(|settings| settings.autosync.interval())
            .unwrap_or_else(|| AutosyncSettings::default().interval())
    }

    fn enabled(&self) -> bool {
        self.settings
            .as_ref()
            .is_some_and(|settings| settings.autosync.enabled)
    }

    /// The full check. `forced` (Sync now) ignores the pause.
    pub async fn check(&mut self, now: Millis, forced: bool) {
        if !self.reload_settings(now).await || !self.enabled() || (self.paused && !forced) {
            self.publish();
            return;
        }
        let Some(settings) = self.settings.clone() else {
            return;
        };
        let work = Arc::clone(&self.work);
        let output = match tokio::task::spawn_blocking(move || work.check(&settings)).await {
            Ok(Ok(output)) => output,
            Ok(Err(err)) => {
                self.record_check(now, format!("Check failed: {err}"));
                self.publish();
                return;
            }
            Err(err) => {
                self.record_check(now, format!("Check failed: {err}"));
                self.publish();
                return;
            }
        };
        self.probes.set_game_dirs(output.game_dirs);
        self.blocked = match &output.result {
            CheckResult::Blocked { platforms } => platforms.clone(),
            _ => Vec::new(),
        };
        self.record_check(now, describe_result(&output.result));
        let (steam_running, game_running) = self.read_probes();
        self.handle(Event::Checked {
            result: output.result,
            steam_running,
            game_running,
            now,
        })
        .await;
    }

    /// The cheap 5 s tick: only the OS readings.
    pub async fn probe(&mut self, now: Millis) {
        if !self.enabled() {
            return;
        }
        let (steam_running, game_running) = self.read_probes();
        self.handle(Event::Probed {
            steam_running,
            game_running,
            now,
        })
        .await;
    }

    pub async fn input(&mut self, input: RunnerInput, now: Millis) {
        match input {
            RunnerInput::RestartNow => self.handle(Event::RestartNow).await,
            RunnerInput::NotNow => self.handle(Event::NotNow).await,
            RunnerInput::SyncNow => {
                if self.is_idle() {
                    self.check(now, true).await;
                } else {
                    let (steam_running, game_running) = self.read_probes();
                    self.handle(Event::SyncNow {
                        steam_running,
                        game_running,
                    })
                    .await;
                }
            }
            RunnerInput::TogglePause => {
                self.paused = !self.paused;
                self.ui.set_paused(self.paused);
                self.publish();
            }
            RunnerInput::SettingsChanged => {
                self.reload_settings(now).await;
                self.publish();
            }
        }
    }

    /// Whether settings could be read. When not, the check is skipped and recorded.
    async fn reload_settings(&mut self, now: Millis) -> bool {
        let work = Arc::clone(&self.work);
        let loaded = match tokio::task::spawn_blocking(move || work.load_settings()).await {
            Ok(result) => result,
            Err(err) => Err(err.to_string()),
        };
        let settings = match loaded {
            Ok(settings) => settings,
            Err(err) => {
                eprintln!("Autosync skipped a check, the settings could not be read: {err}");
                self.record_check(now, format!("Settings unreadable: {err}"));
                return false;
            }
        };
        let previous = self
            .settings
            .as_ref()
            .map(|settings| settings.autosync.clone());
        if previous.as_ref() != Some(&settings.autosync) {
            self.ui.set_autostart(
                settings.autosync.enabled && settings.autosync.start_with_windows,
            );
        }
        self.machine
            .set_countdown(millis(settings.autosync.countdown()));
        let enabled = settings.autosync.enabled;
        self.settings = Some(settings);
        if !enabled {
            for effect in self.machine.reset() {
                self.apply(effect).await;
            }
        }
        true
    }

    fn read_probes(&self) -> (bool, bool) {
        let steam_running = self.probes.steam_running();
        let signals = self.probes.game_signals();
        let game_running = !signals.is_empty();
        let mut status = lock_status(&self.status);
        status.steam_running = Some(steam_running);
        status.game_signals = signals;
        (steam_running, game_running)
    }

    async fn handle(&mut self, event: Event) {
        let mut queue = VecDeque::from([event]);
        while let Some(event) = queue.pop_front() {
            for effect in self.machine.handle(event) {
                if let Some(next) = self.apply(effect).await {
                    queue.push_back(next);
                }
            }
        }
        self.publish();
    }

    async fn apply(&mut self, effect: Effect) -> Option<Event> {
        match effect {
            Effect::ShowPrompt { change, deadline } => {
                lock_status(&self.status).prompt = Some(PromptInfo {
                    summary: change.summary(),
                    deadline_ms: deadline,
                });
                self.ui.show_prompt();
                None
            }
            Effect::HidePrompt => {
                lock_status(&self.status).prompt = None;
                self.ui.hide_prompt();
                None
            }
            Effect::Notify(text) => {
                self.ui.notify(&text);
                None
            }
            Effect::StartSync { restart_steam } => {
                self.publish();
                let outcome = self.run_sync(restart_steam).await;
                if let Some(err) = &outcome.steam_start_error {
                    self.ui
                        .notify(&format!("Steam could not be started again: {err}"));
                }
                Some(Event::SyncFinished {
                    error: outcome.import.err(),
                })
            }
        }
    }

    async fn run_sync(&self, restart_steam: bool) -> ExecOutcome {
        let Some(settings) = self.settings.clone() else {
            return ExecOutcome {
                import: Err("Settings are not loaded".to_string()),
                steam_start_error: None,
            };
        };
        let work = Arc::clone(&self.work);
        tokio::task::spawn_blocking(move || work.sync(&settings, restart_steam))
            .await
            .unwrap_or_else(|err| ExecOutcome {
                import: Err(format!("The import stopped unexpectedly: {err}")),
                steam_start_error: None,
            })
    }

    fn record_check(&self, now: Millis, text: String) {
        let mut status = lock_status(&self.status);
        status.last_check_ms = Some(now);
        status.last_check = Some(text);
    }

    fn publish(&self) {
        let summary = describe(
            self.machine.state(),
            self.enabled(),
            self.paused,
            &self.blocked,
        );
        {
            let mut status = lock_status(&self.status);
            status.enabled = self.enabled();
            status.paused = self.paused;
            status.summary = summary.clone();
        }
        self.ui.set_tooltip(&summary);
    }
}

/// Runs until every input sender is gone. The first check happens at once.
pub async fn run_loop(mut runner: Runner, mut inputs: UnboundedReceiver<RunnerInput>) {
    let mut ticker = tokio::time::interval(PROBE_TICK);
    ticker.set_missed_tick_behavior(tokio::time::MissedTickBehavior::Delay);
    let mut next_check = tokio::time::Instant::now();
    loop {
        tokio::select! {
            _ = ticker.tick() => {
                if tokio::time::Instant::now() >= next_check {
                    runner.check(now_ms(), false).await;
                    next_check = tokio::time::Instant::now() + runner.interval();
                } else if !runner.is_idle() {
                    runner.probe(now_ms()).await;
                }
            }
            input = inputs.recv() => match input {
                Some(input) => runner.input(input, now_ms()).await,
                None => break,
            },
        }
    }
}
```

No `MutexGuard` is held across an `.await` (each `lock_status(...)` is a temporary or a block-scoped guard), so `run_loop`'s future is `Send` for `tauri::async_runtime::spawn`.

```rust
pub fn setup(app: &mut tauri::App) -> Result<(), Box<dyn std::error::Error>> {
    let handle = app.handle().clone();
    let Some(probes) = create_probes() else {
        app.manage(AutosyncHandle::unavailable());
        return Ok(());
    };
    let status: SharedStatus = Arc::new(Mutex::new(AutosyncStatus {
        available: true,
        ..AutosyncStatus::default()
    }));
    let (inputs, receiver) = unbounded_channel();

    let pause_item = MenuItem::with_id(&handle, MENU_PAUSE, "Pause autosync", true, None::<&str>)?;
    build_tray(&handle, &pause_item, inputs.clone())?;

    let ui = Arc::new(TauriUi {
        app: handle.clone(),
        pause_item,
    });
    let runner = Runner::new(Arc::new(LiveWork), probes.clone(), ui, status.clone());
    app.manage(AutosyncHandle {
        inputs: Some(inputs),
        status,
        probes: Some(probes),
    });
    tauri::async_runtime::spawn(run_loop(runner, receiver));
    Ok(())

fn build_tray(
    app: &AppHandle,
    pause_item: &MenuItem<Wry>,
    inputs: UnboundedSender<RunnerInput>,
) -> tauri::Result<()> {
    let open = MenuItem::with_id(app, MENU_OPEN, "Open BoilR", true, None::<&str>)?;
    let sync_now = MenuItem::with_id(app, MENU_SYNC, "Sync now", true, None::<&str>)?;
    let quit = MenuItem::with_id(app, MENU_QUIT, "Quit", true, None::<&str>)?;
    let menu = Menu::with_items(app, &[&open, &sync_now, pause_item, &quit])?;

    let mut tray = TrayIconBuilder::with_id(TRAY_ID)
        .menu(&menu)
        .tooltip("BoilR")
        .on_menu_event(move |app, event| {
            let input = match event.id().as_ref() {
                MENU_OPEN => {
                    show_main(app);
                    return;
                }
                MENU_QUIT => {
                    app.exit(0);
                    return;
                }
                MENU_SYNC => RunnerInput::SyncNow,
                MENU_PAUSE => RunnerInput::TogglePause,
                _ => return,
            };
            if inputs.send(input).is_err() {
                eprintln!("Autosync has stopped; the tray menu has nothing to talk to");
            }
        });
    if let Some(icon) = app.default_window_icon() {
        tray = tray.icon(icon.clone());
    }
    tray.build(app)?;
    Ok(())
}

impl AutosyncUi for TauriUi {

        if let Some(window) = self.app.get_webview_window(PROMPT_LABEL) {
            if let Err(err) = window.destroy() {
                eprintln!("Could not close the autosync prompt: {err}");
            }
        }
    }

    fn notify(&self, text: &str) {
        if let Err(err) = self
            .app
            .notification()
            .builder()
            .title("BoilR")
            .body(text)
            .show()
        {
            eprintln!("Could not show a notification: {err}");
        }
    }

    fn set_tooltip(&self, text: &str) {
        if let Some(tray) = self.app.tray_by_id(TRAY_ID) {
            if let Err(err) = tray.set_tooltip(Some(text)) {
                eprintln!("Could not update the tray tooltip: {err}");
            }
        }
    }

    fn set_paused(&self, paused: bool) {
        let label = if paused {
            "Resume autosync"
        } else {
            "Pause autosync"
        };
        if let Err(err) = self.pause_item.set_text(label) {
            eprintln!("Could not update the tray menu: {err}");
        }
    }

    fn set_autostart(&self, enabled: bool) {
        let autostart = self.app.autolaunch();
        let result = match autostart.is_enabled() {
            Ok(current) if current == enabled => Ok(()),
            _ if enabled => autostart.enable(),
            _ => autostart.disable(),
        };

    }

fn open_prompt(app: &AppHandle) -> tauri::Result<()> {
    let (x, y) = match app.primary_monitor() {
        Ok(Some(monitor)) => {
            let scale = monitor.scale_factor();
            let position = monitor.position();
```

```tsx
        .then(setInfo)

      void load();

      setBusy(false);
    }
```
